Cuando la base falla

El modal no se cierra, ningún campo se limpia y el error aparece arriba del contenido. El botón principal cambia a “Reintentar”. El mensaje técnico puede venir de la base, pero la interfaz siempre aclara que los cambios siguen ahí.

Decisión para 390 px

El modal ocupa la pantalla completa. Cabecera, barra y pie no se pierden; solo se desplaza el cuerpo. Los pasos tienen un ancho mínimo de 92 px, los nombres usan hasta dos líneas y la barra lleva el paso activo al centro.

Anatomía de navegación

La misma barra con 3, 4 y 6 pasos

La barra no comprime los nombres hasta volverlos ilegibles. Cuando no caben, se desplaza horizontalmente. Los pasos futuros quedan visibles, pero bloqueados hasta validar el actual.

3 pasostodos caben
4 pasosnombre largo
6 pasosdesplazable

Pantalla angosta: el nombre nunca desaparece ni se reduce a un punto sin contexto. La barra conserva números, nombres de hasta dos líneas y desplazamiento con el dedo. “Paso 3 de 6” queda siempre visible arriba.

Entrega técnica

Se pega sin cambiar la arquitectura

Cada modal conserva sus identificadores y todos sus campos. Las funciones actuales siguen leyendo el DOM; la cáscara solo muestra un bloque por vez y llama las funciones de guardar que ya existen.

1. Carga única: agrega /frate-modal.js junto a /frate-afiche.js.
2. HTML existente: envuelve los campos de cada pregunta en [data-fm-step]. No cambies sus ID.
3. Validación: usa required para lo simple y validarPaso para reglas cruzadas.
4. Guardado: conecta guardarBorrador y enviar con las funciones actuales.
5. Error: deja que la promesa rechace. El componente conserva todo y muestra “Reintentar”.
